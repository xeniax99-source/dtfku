ONLINE-PRAXIS · ABSICHT · WIDMUNG

So nutzen Sie die Online-Gebetsmühle

Diese kurze Anleitung erklärt die Wahl der Umdrehungen, den Zähler, den Start der Testanimation und den Umgang mit einem Wunsch.

ANZAHL DER UMDREHUNGEN · LOKALE ANIMATION

Wählen Sie die Anzahl der Umdrehungen.
Der Zähler erfasst nur abgeschlossene Drehungen.

Wählen Sie auf der Startseite eine Vorgabe — 7, 21, 108 oder 1.008 Umdrehungen — oder geben Sie eine eigene Zahl von 1 bis 5.000 ein. Der Gesamtzähler auf diesem Gerät steigt nur, wenn eine Umdrehung vollständig abgeschlossen ist.

Wenn in den Geräteeinstellungen „Bewegung reduzieren“ aktiviert ist, führt die Animation höchstens zehn Umdrehungen aus. Der angezeigte Testbetrag richtet sich trotzdem nach der gewählten Zahl; es wird nichts abgebucht.

SCHRITT FÜR SCHRITT · ONLINE-PRAXIS

Formulieren Sie einen Wunsch.
Wählen Sie eine Zahl.
Starten Sie das Rad.

Mehr braucht die Anwendung nicht: einen optionalen Wunsch, eine Zahl und Ihren Start. Sie können „Om mani padme hum“ rezitieren oder die Pause in Stille verbringen.

01

Ein kurzer Wunsch

Schreiben Sie einen Wunsch mit bis zu 200 Zeichen oder behalten Sie ihn in Gedanken; das Feld ist optional.

02

Zahl auswählen

Wählen Sie eine der vier Vorgaben oder geben Sie eine eigene Zahl von 1 bis 5.000 ein. Mit der Bestätigung startet die Animation; der angezeigte Betrag dient nur dem Test.

03

Drehen lassen und widmen

Beobachten Sie die Animation, rezitieren Sie ein Mantra oder bleiben Sie einfach bei Ihrer Absicht. Der Zähler addiert abgeschlossene Umdrehungen; zum Abschluss können Sie den guten Wunsch dem Wohl aller Wesen widmen.

DATENSCHUTZ · TESTMODUS

Ihr Wunsch bleibt bei Ihnen.
Es wird nichts abgebucht.

Ihr Wunsch wird nicht automatisch gespeichert. Nur wenn Sie das separate Einwilligungsfeld aktiv ankreuzen, wird er im Journal dieses Browsers auf diesem Gerät gespeichert. Die Einträge werden nicht an einen Server gesendet und lassen sich löschen.

Der angezeigte Betrag dient nur der Demonstration: Es ist kein Zahlungsanbieter angeschlossen, es wird kein Geld abgebucht und es werden keine Kartendaten abgefragt oder erhoben.

Die Online-Animation ist ein zeitgemäßes digitales Format; sie ersetzt weder ein physisches Mani-Gebetsrad noch die Anleitung einer bestimmten buddhistischen Gemeinschaft.
