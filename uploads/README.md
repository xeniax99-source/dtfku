# «В круге» — молитвенное колесо и практика сострадания

Статический многостраничный сайт на русском, английском, французском и немецком языках. Он рассказывает о тибетском мани-колесе, мантре «Ом мани падме хум», рецитации, метта, шаматхе и посвящении блага. Практики описаны в их буддийских контекстах; они не представлены как части одного обязательного обряда.

## Страницы

- `index.html` — главная страница, вращающееся колесо и краткое молитвенное руководство.
- `prayers.html` — мантра Авалокитешвары, прибежище, устремление к пробуждению и посвящение заслуги.
- `practices.html` — рецитация, вращение мани-колеса, обход ступы, шаматха, метта и короткая практика.
- `wheel.html` — устройство колеса, свиток с мантрой и значение молитвенного жеста.
- `/en/`, `/fr/`, `/de/` — статические языковые версии всех четырёх страниц.

## Локальная разработка

Для просмотра запустите статический HTTP-сервер из корня проекта, например:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для корректной работы языковых маршрутов используйте HTTP, а не `file://`.

После изменения исходных страниц или переводов пересоберите локализованные HTML-файлы:

```bash
node build_locales.js
```

Словари и тексты интерфейса находятся в `locales.js`; общая логика навигации, счётчика и вращения — в `script.js`; оформление — в `styles.css`.

## Счётчик и личные пожелания

Колесо совершает десять полных оборотов примерно за 24 секунды. При включённом у посетителя режиме уменьшения движения выполняется один оборот примерно за 1,2 секунды. Счётчик прибавляет только завершённые обороты и хранит число в браузере на этом устройстве; общего счёта посетителей сайт не показывает.

Текст пожелания не сохраняется автоматически. Он попадает в личный журнал только после отдельного согласия — если посетитель отмечает соответствующий флажок. Сохранённые записи находятся в хранилище браузера на этом устройстве, не отправляются сайтом и могут быть удалены по одной или все сразу. Журнал хранит не более 50 записей. Сайт не обрабатывает платежи.

## SEO и публикация

У страниц заданы отдельные заголовки и описания, относительные canonical-ссылки, Open Graph / Twitter metadata и описания изображений. Публичный домен намеренно не прописан. После выбора фактического HTTPS-домена пересоберите языковые страницы и передайте домен генератору:

```bash
node build_locales.js
python3 generate_sitemap.py --base-url https://ваш-домен.example
```

Генератор финализирует абсолютные canonical URL, `hreflang`, URL изображений, `robots.txt` и `sitemap.xml`. До указания настоящего домена проект не публикует доменные SEO-адреса-заглушки.

## Иконки и установка

`assets/site.webmanifest` содержит метаданные веб-приложения, обычные и maskable PNG-иконки, а также быстрые ссылки на страницы молитв и практик. Для Safari предусмотрена отдельная Apple touch icon; favicon доступны в SVG, PNG и ICO.
